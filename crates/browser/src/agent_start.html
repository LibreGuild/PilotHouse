Controlled by PilotHouse

PilotHouse Chrome

This is the browser your PilotHouse agents use for real websites. It has a profile of its own, apart from your everyday Chrome, so what happens here stays here.

Sign in once, here

Sites you sign in to in this window stay signed in, for every agent and every chat.

Watch them work

A violet glow and a pointer show the tab an agent is using. Press Stop on it to pause that agent.

Your tabs stay yours

Each agent works in tabs of its own. Ask one to take over the tab you are on, and it finishes what you started.

Passwords are for you

Agents never type passwords or solve "I'm not a robot" checks. They ask you to, in this window.

Logs for debugging

Agents read each page's console and network requests, with sign-in headers hidden.

Downloads in one place

Files from this window go to the PilotHouse folder in your Downloads.

Open it any time from PilotHouse's command palette: “Open PilotHouse Chrome”. Close it whenever you like; agents open it again when they need it.
