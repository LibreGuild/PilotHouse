# Your own icons

Put SVG icons here, one per file, named in lowercase letters, digits, `-` and
`_` (`reports.svg`). They are built into the app; draw one with
`ph_ui::custom_icon("reports")`, for example as the icon of a view of your own
(`crates/custom`). Icons drawn like Lucide's (24 × 24, `stroke="currentColor"`)
take the theme's colors. See docs/customizing.md.
